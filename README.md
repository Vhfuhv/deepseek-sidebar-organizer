# DeepSeek Scroll Assistant

DeepSeek Scroll Assistant 是一个 Chromium Manifest V3 扩展，用于增强 DeepSeek 对话页面中当前活动对话区域的滚动体验。

## 严格站点范围

扩展内容脚本仅匹配 `https://chat.deepseek.com/*`。它不会在其他站点运行，也不支持非 Chromium 浏览器。首个版本不提供键盘快捷键。

## 功能

- 为当前活动对话滚动区域提供高对比度滚动条，默认宽度为 14px。
- 根据网页的浅色或深色主题自动使用推荐配色；手动选择滑块或轨道颜色后，手动颜色优先。
- 通过工具栏弹窗启用或禁用扩展、调整滚动条宽度（8px 至 24px）、设置滑块和轨道颜色，或恢复推荐值。
- 滚动对话时在右侧短暂显示当前位置百分比，约 900 毫秒无滚动后淡出。
- 提供“顶部”和“最新”按钮，平滑跳转到对话起点或最新消息；已到达对应位置时，按钮会隐藏。
- 在切换对话、页面重渲染或流式回复时重新定位当前对话滚动区域，避免重复插入百分比标签和操作按钮。

## 隐私

扩展不读取、保存或传输聊天内容。它只将启用状态、滚动条宽度以及可选的滑块和轨道颜色保存到 Chromium 的 `chrome.storage.sync` 中，以便在浏览器会话之间保留配置。弹窗不会检查页面内容。

## 安装（Chromium）

1. 在 Chrome、Edge 或其他 Chromium 浏览器中打开 `chrome://extensions/`。
2. 打开页面右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”（Load unpacked）。
4. 选择本仓库目录，即包含 `manifest.json` 的 `deepseek-scroll-assistant` 目录。
5. 需要更新扩展文件时，回到扩展管理页并点击该扩展的“重新加载”。

## 弹窗使用

1. 打开 `https://chat.deepseek.com/` 中有足够消息可滚动的对话。
2. 点击浏览器工具栏中的 DeepSeek Scroll Assistant 扩展图标。
3. 使用“启用增强”开关立即启用或移除当前页面的增强效果。
4. 拖动“滚动条宽度”滑块设置 8px 至 24px 的宽度，当前像素值会显示在控件旁。
5. 使用“滑块颜色”和“轨道颜色”选择自定义颜色。选择任一颜色后，该颜色不会再跟随页面主题自动变化。
6. 点击“恢复推荐值”以重新启用默认 14px 宽度和随浅色、深色主题自动适配的推荐颜色。

## 手动验证

在加载或重新加载未打包扩展后，使用一段足够长的 DeepSeek 对话执行以下验证：

1. 在浅色模式打开长对话，确认只有当前对话的滚动条变得清晰、较宽且高对比度。
2. 切换到深色模式，确认当前对话滚动条仍有足够对比度。
3. 滚动对话，确认百分比标签准确反映当前位置，并在停止滚动约 900 毫秒后淡出。
4. 确认“顶部”和“最新”按钮可正确平滑导航，并分别在顶部和底部隐藏。
5. 逐项修改弹窗控件，确认活动标签页中的效果立即更新。
6. 重新加载 DeepSeek 页面并重启浏览器，确认设置仍会保留。
7. 切换对话并等待流式回复，确认控件能随页面变化继续工作，且不会出现重复标签或按钮。
8. 在弹窗中禁用扩展，确认注入的控件和自定义滚动条外观都会移除。
